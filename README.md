# Chess-Game — mobile update

Replace `index.html` in your Chess-Game repo with this one, then commit + push.
The Pages workflow deploys it automatically.

What's new for phones:
- Compact header (2 rows instead of 3), bigger tap targets (44px-ish buttons)
- Inspector + captures panels become a bottom sheet, hidden by default —
  tap the **Info** pill (bottom right) to open/close them
- Portrait camera pulls back + widens FOV so the whole board fits on screen
- Pinch-to-zoom with two fingers; single-finger drag still orbits, tap still selects
- Page can't scroll/zoom while playing; modals fit small screens; safe-area padding

Desktop is unchanged.
